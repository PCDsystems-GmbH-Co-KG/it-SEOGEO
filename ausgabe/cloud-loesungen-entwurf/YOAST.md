## Canonical: bewusst noch leer

`/cloud-loesungen/` leitet derzeit per 301 auf `/cloud-loesungen-entwurf/` um.
Ein Canonical auf `/cloud-loesungen/` würde jetzt eine Schleife erzeugen (Canonical zeigt auf Umleitung, die zurück zeigt).
Yoast setzt ohne Eintrag automatisch die eigene URL. Eintragen erst beim Go-live:

1. Umleitung `/cloud-loesungen/` entfernen.
2. Slug (Titelform) von `cloud-loesungen-entwurf` auf `cloud-loesungen` ändern.
3. Seitentitel ohne "(Entwurf)".
4. Canonical leer lassen (Selbst-Canonical) oder `https://www.pcd-systems.de/cloud-loesungen/` eintragen.
